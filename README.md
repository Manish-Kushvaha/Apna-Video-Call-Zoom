# 🎥 Apna Video Call – Zoom Clone

**Apna Video Call** is a real-time video calling platform inspired by Zoom, developed to enable **peer-to-peer video communication** using modern web technologies. The project focuses on **real-time connectivity, smooth user interaction, and scalable architecture**.

---

## 🚀 Project Overview

- Built a **real-time video calling platform** inspired by Zoom  
- Implemented **peer-to-peer communication** using **WebRTC**  
- Developed the frontend using **React.js** with responsive video layouts  
- Designed a **signaling server** using **Express.js** to manage user connections  
- Utilized **MongoDB** for storing user session data  
- Structured the project to support future features such as **chat and call history**

---

## ✨ Key Features

- Real-time video and audio communication  
- Peer-to-peer connection using WebRTC  
- Responsive video grid for multiple users  
- Signaling server for connection setup  
- Scalable architecture for future enhancements  

---

## 🧰 Tech Stack

- **Frontend:** React.js  
- **Realtime Communication:** WebRTC  
- **Backend / Signaling Server:** Express.js  
- **Database:** MongoDB
